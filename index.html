INSTALL

安装部署

三步即可搭建属于你的社区

1

环境准备

确保服务器已安装 PHP 8.0+ 与 MySQL 5.7+，开启 PDO 扩展。推荐使用宝塔面板、phpStudy 或 Nginx + PHP-FPM。

PHP 8.0+ MySQL 5.7+ PDO 扩展
2

上传源码

将解压后的全部文件上传至网站根目录，确保 config/ 与 assets/uploads/ 目录有写入权限。

起灵贴吧/
├── admin/ 后台管理
├── api/ 接口
├── pages/ 前台页面
├── includes/ 公共文件
├── assets/ 静态资源
├── config/ 数据库配置
└── index.php 入口文件
3

一键安装

浏览器访问域名，系统自动跳转至安装页面。填写数据库信息与管理员账号，点击安装即可自动创建数据表并完成初始化。
